# Mitwirken / Contributing

## Deutsch

Fehlerberichte und Vorschläge sind willkommen. Beschreibe dabei Windows-Version, die betroffene Funktion und eine nachvollziehbare Schrittfolge. Lade keine persönlichen Spielstände, Logs oder originalen Spieldateien hoch. Änderungen sollen die geprüfte 68-Byte-Datei unverändert lassen, wenn das Format nicht eindeutig unterstützt wird.

## English

Bug reports and suggestions are welcome. Include the Windows version, affected feature, and reproducible steps. Do not upload personal game data, logs, or original game files. Changes should leave files untouched when their format is not explicitly supported; the current supported format is the verified 68-byte variant.

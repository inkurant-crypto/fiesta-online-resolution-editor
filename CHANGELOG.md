# Änderungsprotokoll / Changelog

## 1.7 — 2026-11-07

### Deutsch

- Deutsche und englische Oberfläche mit automatischer Erkennung der Windows-Anzeigesprache.
- Spielordner durchsuchen und passende `Option.mco` finden.
- Auflösungsmodi verbundener Monitore anzeigen; eigene Werte bleiben möglich.
- Änderungsvorschau, Sicherungen, gespeicherte Standardkonfiguration und Wiederherstellung.
- Fiesta-Status und Änderungen an der Datei seit dem Laden erkennen.
- Auswahl zwischen Fenster- und Vollbildmodus.

### English

- German and English interface with automatic detection of the Windows display language.
- Search a game folder for `Option.mco`.
- List display modes reported for connected monitors while still allowing custom values.
- Change preview, backups, saved default configuration, and restore options.
- Detect the Fiesta process and changes to the file since loading.
- Choose between windowed and fullscreen mode.
